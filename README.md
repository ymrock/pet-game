# 🍜 食べ歩きリスト

行きたい食べ物屋さんを登録しておき、行ったらチェックして「日付・評価・金額・感想」などを記録できるWebアプリです。
スマホ・PCのブラウザで動きます（ビルド不要・サーバー不要）。

## できること

- **お店の登録**：店名、ジャンル、エリア・住所、URL（食べログ・Instagram など）、行きたい度（★1〜5）、メモ
- **行ったらチェック**：カードの ○（または「✓ 行った！」）をタップすると記録画面が開きます
  - 行った日（初期値は今日）、評価（★1〜5）、金額、一緒に行った人、食べたもの、感想、「また行きたい！」
  - 同じお店に何度でも記録を追加でき、平均評価・平均金額が表示されます
- **一覧**：「行きたい／行った／すべて」のタブ、キーワード検索、ジャンル絞り込み、並び替え（登録順・行きたい度・評価・最近行った順・店名）
- **地図**：Google マップで店名＋エリアを検索
- **バックアップ**：右上「⋯」メニューから JSON の保存・復元、Excel 等で開ける CSV 書き出し

データはブラウザ内（localStorage）に保存されます。機種変更やブラウザのデータ削除の前に、メニューからバックアップを保存してください。

## 使い方

### パソコンですぐ試す

`index.html` をブラウザで開くだけで使えます。

### スマホで使う（GitHub Pages）

1. GitHub のリポジトリ設定 → **Pages** → Source を「Deploy from a branch」にし、このブランチ（またはマージ後の main）の `/ (root)` を選んで保存
2. 表示された URL（`https://<ユーザー名>.github.io/<リポジトリ名>/`）をスマホで開く
3. 共有メニューから「ホーム画面に追加」するとアプリのように起動でき、オフラインでも開けます
